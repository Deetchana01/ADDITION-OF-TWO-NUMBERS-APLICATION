# Addition of Two Numbers - Android Application

## Overview
This project is an Android application developed using Android Studio. The application accepts two numbers from the user and calculates their sum. The summation value is displayed in a TextView after clicking the ADD button.

## Features
- Enter two numbers from the user
- Perform addition operation
- Display the result instantly
- Simple and user-friendly interface

## Technologies Used

- Java

## How to Run the Application

1. Open Android Studio.
2. Open the project folder.
3. Connect an emulator or Android device.
4. Click the **Run** button.
5. Enter two numbers and click the ADD button.
6. The sum result will be displayed.

## Working Procedure

1. User enters the first number.
2. User enters the second number.
3. The ADD button performs the addition operation.
4. The calculated sum is displayed in the TextView.
